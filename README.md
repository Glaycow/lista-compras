# ListaCompras

App Angular 22 (zoneless) para listas de compras, com persistência local via Dexie/IndexedDB.

## Desenvolvimento

```bash
npm start
```

Abra `http://localhost:4200/`.

## Build

```bash
npm run build
```

## Testes

```bash
npm test
```

Usa Vitest (não Karma).

## Lint

```bash
npm run lint
```
